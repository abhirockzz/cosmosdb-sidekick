Capabilities

Everything you need to explore your data

Query in Plain English

Ask questions about your data naturally. The AI writes SQL, executes it against the emulator, and returns results with RU cost.

Write & Insert Data

Generate realistic test documents and upsert them directly. Ask for bulk inserts or single documents — it handles both.

Context-Aware

Auto-detects the active database and container from the Data Explorer. Context updates live as you switch between tabs.

Persistent Conversations

Streaming responses, full chat history, and follow-ups. Conversations survive tab switches and panel reopens.

Setup

Get started in minutes

Four steps to have the extension running against your local Azure Cosmos DB emulator.

Step 01

Clone the repository

Grab the source code from GitHub.

$ git clone https://github.com/abhirockzz/cosmosdb-sidekick.git
Step 02

Build the sidecar

Install dependencies and compile TypeScript.

$ cd sidecar && npm install
Step 03

Load the extension

Open chrome://extensions, enable Developer mode, click Load unpacked → select the extension/ folder.

Step 04

Start the sidecar

Keep this running in a terminal while you use the extension.

$ cd sidecar && npm start

Experimental project — not an official Microsoft or Azure offering. AI-generated responses may be inaccurate. Always review queries before running them.
